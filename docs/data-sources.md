# Data sources

The data source vocabulary is the top-level `dataSources` in [matrix.json](../matrix.json): telemetry a defender can collect to see a technique. Each entry's `readBy` cites the code of a tool or sensor that reads the data, at a pinned commit, and `scripts/validate_matrix.py` refuses an entry with no citation. A technique's `dataSources` names each source with the check, signature or sensor field that uses it for that technique, and the technique's page shows the source by its name. This page is rendered from matrix.json: `python3 scripts/check_technique_pages.py` fails when it differs, and `--fix` rewrites it.
