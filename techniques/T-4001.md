# T-4001: Capability Override

**Tactic:** privilege-escalation
**Attack Class:** SOUL-DELEGATE

## Description

Override declared capability restrictions to execute unauthorized operations like shell commands

## Procedure Examples

- **DVAA Validation:** CodeBot shell execution

## Detection

- **HMA Checks:** PERM-001, PERM-002, PERM-003
- **OASB Controls:** 2.1, 2.2, 2.3, 2.4, 2.5

## Mitigation

Apply the [OASB-1](https://oasb.ai) controls that matrix.json maps to this technique:

- OASB 2.1
- OASB 2.2
- OASB 2.3
- OASB 2.4
- OASB 2.5
