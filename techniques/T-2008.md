# T-2008: System Prompt Boundary Bypass

**Tactic:** initial-access
**Attack Class:** SOUL-INJECT

## Description

Exploit weak boundaries between system and user prompts to override system-level instructions

## Procedure Examples

- **DVAA Validation:** L3-04

## Detection

- **HMA Checks:** SOUL-OVERRIDE-001
- **OASB Controls:** 3.1, 3.2, 3.3, 3.4, 3.5
- **Data Sources:** Application source code (hackmyagent check SOUL-OVERRIDE-001); Skill definition file (hackmyagent check SOUL-OVERRIDE-001)

## Mitigation

Apply the [OASB-1](https://oasb.ai) controls that matrix.json maps to this technique:

- OASB 3.1: Prompt Injection Protection
- OASB 3.2: Instruction Boundary Enforcement
- OASB 3.3: Input Validation
- OASB 3.4: URL and Resource Validation
- OASB 3.5: Multi-Modal Input Security
