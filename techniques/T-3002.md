# T-3002: Environment Variable Leakage

**Tactic:** credential-harvest
**Attack Class:** NEMO-CRED-LEAK

## Description

Access environment variables containing API keys, tokens, and connection strings

## Procedure Examples

- **DVAA Validation:** env var leakage

## Detection

- **HMA Checks:** ENV-001, ENV-002, ENV-003, ENV-004
- **OASB Controls:** 5.1, 5.2, 5.3, 5.4, 5.5
- **Data Sources:** Environment file (hackmyagent check ENV-001, hackmyagent check ENV-002, hackmyagent check ENV-003); Configuration file (hackmyagent check ENV-001, hackmyagent check ENV-002, hackmyagent check ENV-003); Package manifest (hackmyagent check ENV-004)

## Mitigation

Apply the [OASB-1](https://oasb.ai) controls that matrix.json maps to this technique:

- OASB 5.1: No Hardcoded Credentials
- OASB 5.2: Context Window Isolation
- OASB 5.3: Credential Scope Limitation
- OASB 5.4: Credential Rotation
- OASB 5.5: Secrets Not Logged

- **Evidence Tier:** observed
