# T-4003: Tool Parameter Injection

**Tactic:** privilege-escalation
**Attack Class:** MCP-EXPLOIT

## Description

Inject malicious parameters into tool calls to escalate privileges or bypass validation

## Procedure Examples

- **DVAA Validation:** MCP parameter injection

## Detection

- **HMA Checks:** PERM-001
- **OASB Controls:** 2.1, 2.2, 2.3, 2.4, 2.5

## Mitigation

Apply the [OASB-1](https://oasb.ai) controls that matrix.json maps to this technique:

- OASB 2.1: Explicit Capability Grants
- OASB 2.2: Least Privilege Principle
- OASB 2.3: Capability Boundaries
- OASB 2.4: No Implicit Trust Escalation
- OASB 2.5: Human-in-the-Loop for Sensitive Actions

## Evidence

- **Evidence Tier:** validated
