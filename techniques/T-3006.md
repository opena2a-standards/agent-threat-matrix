# T-3006: Context Window Credential Leak

**Tactic:** credential-harvest
**Attack Class:** RETROACTIVE-PRIV

## Description

Exploit context window contents to leak credentials that were previously processed by the agent

## Procedure Examples

- **DVAA Validation:** LegacyBot credential leak

## Detection

- **HMA Checks:** CRED-001, AGENT-CRED-001
- **OASB Controls:** 5.1, 5.2, 5.3, 5.4, 5.5
- **Data Sources:** Configuration file (hackmyagent check CRED-001); Environment file (hackmyagent check CRED-001); MCP server configuration (hackmyagent check CRED-001); Agent instruction file (hackmyagent check CRED-001, hackmyagent check AGENT-CRED-001); Application source code (hackmyagent check AGENT-CRED-001)

## Mitigation

Apply the [OASB-1](https://oasb.ai) controls that matrix.json maps to this technique:

- OASB 5.1: No Hardcoded Credentials
- OASB 5.2: Context Window Isolation
- OASB 5.3: Credential Scope Limitation
- OASB 5.4: Credential Rotation
- OASB 5.5: Secrets Not Logged
