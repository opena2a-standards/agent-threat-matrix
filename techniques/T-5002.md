# T-5002: A2A Agent Pivoting

**Tactic:** lateral-movement
**Attack Class:** A2A-EXPOSE

## Description

Pivot from a compromised agent to other agents via A2A protocol connections

## Procedure Examples

- **DVAA Validation:** L4-02

## Detection

- **HMA Checks:** A2A-001, A2A-002
- **OASB Controls:** 10.1, 10.2, 10.3, 10.4, 10.5, 7.1, 7.2, 7.3, 7.4
- **Data Sources:** A2A agent card (hackmyagent check A2A-001); Application source code (hackmyagent check A2A-002)

## Mitigation

Apply the [OASB-1](https://oasb.ai) controls that matrix.json maps to this technique:

- OASB 10.1: Security Event Logging
- OASB 10.2: Anomaly Detection
- OASB 10.3: Kill Switch
- OASB 10.4: Incident Response Procedures
- OASB 10.5: Recovery and Rollback
- OASB 7.1: Mutual Authentication
- OASB 7.2: Message Integrity
- OASB 7.3: Trust Boundary Enforcement
- OASB 7.4: Communication Logging

- **Evidence Tier:** validated
