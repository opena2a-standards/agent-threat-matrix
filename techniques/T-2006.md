# T-2006: Unicode/Encoding Bypass

**Tactic:** initial-access
**Attack Class:** UNICODE-STEGO

## Description

Use Unicode homoglyphs, invisible characters, or encoding tricks to bypass input filters and inject instructions

## Procedure Examples

- **DVAA Validation:** token-smuggling-unicode

## Detection

- **HMA Checks:** UNICODE-STEGO-001, UNICODE-STEGO-002, UNICODE-STEGO-003, UNICODE-STEGO-004, UNICODE-STEGO-005
- **OASB Controls:** 3.1, 3.2, 3.3, 3.4, 3.5
- **Data Sources:** Application source code (hackmyagent check UNICODE-STEGO-001, hackmyagent check UNICODE-STEGO-002, hackmyagent check UNICODE-STEGO-003, hackmyagent check UNICODE-STEGO-004, hackmyagent check UNICODE-STEGO-005)

## Mitigation

Apply the [OASB-1](https://oasb.ai) controls that matrix.json maps to this technique:

- OASB 3.1: Prompt Injection Protection
- OASB 3.2: Instruction Boundary Enforcement
- OASB 3.3: Input Validation
- OASB 3.4: URL and Resource Validation
- OASB 3.5: Multi-Modal Input Security
