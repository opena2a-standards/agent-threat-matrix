# T-6007: Persistent Agent State Manipulation

**Tactic:** persistence
**Attack Class:** PERSIST-STATE

## Description

Attacks that persist across agent sessions via memory poisoning, state tampering, and cached context injection

## Procedure Examples

- **DVAA Validation:** persistent-agent-memory-poison

- **HMA Checks:** PERSIST-001, PERSIST-002, PERSIST-003, PERSIST-004, PERSIST-005, PERSIST-006, PERSIST-007, PERSIST-008, PERSIST-009, PERSIST-010
- **OASB Controls:** 8.1, 8.2, 4.3

## Mitigation

Apply the [OASB-1](https://oasb.ai) controls that matrix.json maps to this technique:

- OASB 8.1: Conversation Integrity
- OASB 8.2: Context Injection Protection
- OASB 4.3: Data Exfiltration Prevention
