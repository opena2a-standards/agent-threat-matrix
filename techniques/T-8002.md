# T-8002: HTTP Callback

**Tactic:** exfiltration
**Attack Class:** SKILL-EXFIL

## Description

Exfiltrate data via HTTP POST requests to attacker-controlled endpoints

## Procedure Examples

- **DVAA Validation:** ToolBot fetch_url POST

## Detection

- **HMA Checks:** NET-001, SANDBOX-001, SANDBOX-002, SANDBOX-003, SANDBOX-004
- **OASB Controls:** 4.3
- **Data Sources:** MCP server configuration (hackmyagent check NET-001); Container definition (hackmyagent check SANDBOX-001, hackmyagent check SANDBOX-002, hackmyagent check SANDBOX-003, hackmyagent check SANDBOX-004)

## Mitigation

## Evidence

Those counts measure engagement with the trap, not confirmed agent behaviour: no fire in the corpus has ever been classified as an agent, and crawler traffic is counted rather than filtered. They did not affect the tier above. See [Honeypot-Derived Evidence](../EVIDENCE_AUDIT.md#honeypot-derived-evidence-what-it-proves-and-what-it-does-not).
