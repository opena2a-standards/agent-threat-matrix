# T-9006: Supply Chain Compromise

**Tactic:** impact
**Attack Class:** NEMO-SUPPLY-CHAIN

## Description

Compromise upstream dependencies, plugins, or MCP servers to affect all downstream agents

## Procedure Examples

- **DVAA Validation:** mcp-rug-pull

## Detection

- **HMA Checks:** SUPPLY-001, SUPPLY-002, SUPPLY-003, SUPPLY-004, DEP-001, DEP-002, DEP-003, DEP-004
- **OASB Controls:** 6.1, 6.2, 6.3, 6.4, 6.5, 10.5
- **Data Sources:** Skill definition file (hackmyagent check SUPPLY-001, hackmyagent check SUPPLY-002, hackmyagent check SUPPLY-003, hackmyagent check SUPPLY-004); Package manifest (hackmyagent check DEP-001, hackmyagent check DEP-002, hackmyagent check DEP-003, hackmyagent check DEP-004)

## Mitigation

Apply the [OASB-1](https://oasb.ai) controls that matrix.json maps to this technique:

- OASB 6.1: Verified Component Sources
- OASB 6.2: Cryptographic Integrity Verification
- OASB 6.3: Rug Pull Protection
- OASB 6.4: Dependency Vulnerability Scanning
- OASB 6.5: Software Bill of Materials
- OASB 10.5: Recovery and Rollback
