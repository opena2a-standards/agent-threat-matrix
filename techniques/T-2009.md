# T-2009: Parser Differential Exploitation

**Tactic:** initial-access
**Attack Class:** PARSER-DIFFERENTIAL

## Description

Exploit differences in how parsers (JSON, YAML, markdown) interpret the same input to bypass security controls

- **DVAA Validation:** parser-differential-json
