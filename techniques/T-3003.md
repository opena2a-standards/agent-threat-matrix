# T-3003: Tool Response Credential Capture

**Tactic:** credential-harvest
**Attack Class:** RETROACTIVE-PRIV

## Description

Capture credentials returned in tool or API responses that pass through the agent's context

## Procedure Examples

- **DVAA Validation:** ToolBot credential responses

## Detection

- **HMA Checks:** CRED-001
- **OASB Controls:** 5.1, 5.2, 5.3, 5.4, 5.5
- **Data Sources:** Configuration file (hackmyagent check CRED-001); Environment file (hackmyagent check CRED-001); MCP server configuration (hackmyagent check CRED-001); Agent instruction file (hackmyagent check CRED-001)

## Mitigation

Apply the [OASB-1](https://oasb.ai) controls that matrix.json maps to this technique:

- OASB 5.1: No Hardcoded Credentials
- OASB 5.2: Context Window Isolation
- OASB 5.3: Credential Scope Limitation
- OASB 5.4: Credential Rotation
- OASB 5.5: Secrets Not Logged

- **Evidence Tier:** validated
