# T-7001: File System Enumeration

**Tactic:** collection
**Attack Class:** NEMO-SANDBOX-ESCAPE

## Description

Enumerate and read files from the agent's accessible file system via path traversal or tool access

## Procedure Examples

- **DVAA Validation:** ToolBot path traversal

## Detection

- **HMA Checks:** IO-001, IO-002, IO-003, IO-004
- **OASB Controls:** 4.1, 4.2, 4.3, 4.4
- **Data Sources:** Package manifest (hackmyagent check IO-001, hackmyagent check IO-002, hackmyagent check IO-003); Application source code (hackmyagent check IO-001, hackmyagent check IO-004)

- OASB 4.1: Output Validation
- OASB 4.2: Action Confirmation for Destructive Operations
- OASB 4.3: Data Exfiltration Prevention
- OASB 4.4: Output Attribution
