# T-2001: Direct Prompt Injection

**Tactic:** initial-access
**Attack Class:** SOUL-INJECT

## Description

Inject malicious instructions directly into agent input to override system prompt behavior

## Procedure Examples

- **DVAA Validation:** L1-03

## Detection

- **HMA Checks:** PROMPT-001, PROMPT-002, PROMPT-003, PROMPT-004
- **OASB Controls:** 3.1, 3.2, 3.3, 3.4, 3.5
- **Data Sources:** Agent instruction file (hackmyagent check PROMPT-001, hackmyagent check PROMPT-002, hackmyagent check PROMPT-003, hackmyagent check PROMPT-004)

## Mitigation

Apply the [OASB-1](https://oasb.ai) controls that matrix.json maps to this technique:

- OASB 3.1: Prompt Injection Protection
- OASB 3.2: Instruction Boundary Enforcement
- OASB 3.3: Input Validation
- OASB 3.4: URL and Resource Validation
- OASB 3.5: Multi-Modal Input Security

## Evidence

- **Evidence Tier:** observed
- **Honeypot Telemetry:** AgentPwn contributes live canary-fire evidence for this technique to the Attack Prevalence Index. Those counts measure engagement with the trap, not confirmed agent behaviour: no fire in the corpus has ever been classified as an agent, and crawler traffic is counted rather than filtered. They did not affect the tier above. See [Honeypot-Derived Evidence](../EVIDENCE_AUDIT.md#honeypot-derived-evidence-what-it-proves-and-what-it-does-not).
