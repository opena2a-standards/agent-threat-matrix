# T-7002: Database Extraction

**Tactic:** collection
**Attack Class:** CODE-INJECTION

## Description

Extract data from databases via SQL injection or authorized database tool access

## Procedure Examples

- **DVAA Validation:** DataBot SQL injection

## Detection

- **HMA Checks:** IO-001, INJ-001, INJ-002, INJ-003
- **OASB Controls:** 4.1, 4.2, 4.3, 4.4

## Mitigation

Apply the [OASB-1](https://oasb.ai) controls that matrix.json maps to this technique:

- OASB 4.1: Output Validation
- OASB 4.2: Action Confirmation for Destructive Operations
- OASB 4.3: Data Exfiltration Prevention
- OASB 4.4: Output Attribution
