# T-3004: Memory Credential Mining

**Tactic:** credential-harvest
**Attack Class:** MEM-POISON

## Description

Extract credentials stored in agent memory from previous sessions or conversations

## Procedure Examples

- **DVAA Validation:** L2-05

## Detection

- **HMA Checks:** MEM-001, MEM-002, MEM-003, MEM-004, MEM-005, MEM-006
- **OASB Controls:** 5.1, 5.2, 5.3, 5.4, 5.5
- **Data Sources:** Agent memory file (hackmyagent check MEM-001); Configuration file (hackmyagent check MEM-002, hackmyagent check MEM-003); Multi-agent configuration (hackmyagent check MEM-004); Application source code (hackmyagent check MEM-005, hackmyagent check MEM-006)

## Mitigation

Apply the [OASB-1](https://oasb.ai) controls that matrix.json maps to this technique:

- OASB 5.1: No Hardcoded Credentials
- OASB 5.2: Context Window Isolation
- OASB 5.3: Credential Scope Limitation
- OASB 5.4: Credential Rotation
- OASB 5.5: Secrets Not Logged
